# ⚡ SetForge — Product Set Composer

Narzędzie do tworzenia zestawów produktowych w formacie 800×800px.
Idealne dla sprzedawców na marketplace i social media.

## ✨ Funkcje

- Układy siatki, wiersz i kaskada (×2 do ×6 produktów)
- Eksport wsadowy do 100 zdjęć naraz jako ZIP
- Formaty PNG, JPG, WebP
- Usuwanie tła z regulowaną tolerancją
- Supersampling 2× dla wysokiej jakości obrazów
- Działa w przeglądarce — bez instalacji
